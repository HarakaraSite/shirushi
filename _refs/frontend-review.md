# Shirushi フロントエンド確認メモ

> 確認日: 2026-06-13

## 対象ファイル

- `static/index.html`
- `static/css/style.css`
- `static/js/app.js`

## 修正候補

### 1. タグ入力イベントの重複登録

対応状況: 対応済み（2026-06-14）

`showMainScreen()` のたびに `setupTagInput()` が呼ばれており、ログアウト後の再ログインなどで `input` / `keydown` / `document click` のイベントリスナーが重複登録される可能性があります。

影響:

- タグ入力欄で Enter を押したとき、タグ作成・選択処理が複数回走る可能性がある。

対応案:

- `setupTagInput()` に初期化済みフラグを持たせ、一度だけイベント登録する。

### 2. 認証チェック時のエラー処理

対応状況: 対応済み（2026-06-14）

`checkAuth()` は `/api/bookmarks` のレスポンスが `401` 以外ならログイン済みとして扱っています。

影響:

- サーバーエラーや壊れたJSONなど、`401` 以外の異常系でもメイン画面に進んでしまう。

対応案:

- `res.ok` を確認し、`401` 以外の失敗時はエラー表示またはログイン画面へ戻す。

### 3. ヘッダーのモバイル表示

対応状況: 対応済み（2026-06-14）

ヘッダーのボタン群 `.header-actions` が横並び固定で、`flex-wrap` がありません。

影響:

- スマホ幅で「追加 / エクスポート / インポート / タグ管理 / ログアウト」が横にはみ出す可能性がある。

対応案:

- `.header-actions` に `flex-wrap: wrap` を追加する。
- 必要に応じてヘッダー全体も縦積みできるようメディアクエリを追加する。

### 4. 一括操作バーのモバイル表示

対応状況: 対応済み（2026-06-14）

一括操作バー `#bulk-bar` も横並び固定で、ボタン数が多い状態です。

影響:

- 狭い画面で一括操作ボタンがはみ出す、または押しづらくなる可能性がある。

対応案:

- `#bulk-bar` に `flex-wrap: wrap` を追加する。
- `bulk-cancel` の `margin-left: auto` が折り返し時に不自然にならないか確認する。

### 5. パスワード入力の autocomplete

対応状況: 対応済み（2026-06-14）

ログイン画面のパスワード入力に `autocomplete` 属性がありません。

影響:

- ブラウザの警告が出る。
- パスワードマネージャーの補助が効きにくい可能性がある。

対応案:

- `<input type="password" ... autocomplete="current-password">` を指定する。

## 確認済みの良い点

- ユーザーデータの描画はおおむね `escapeHtml()` 経由になっている。
- リンクURLは `safeHref()` で `http` / `https` に制限されている。
- タグ名やブックマークJSONを `onclick` に直接埋め込まず、ID経由で参照する設計になっている。
