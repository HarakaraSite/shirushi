# Henji 本文要約 MVP モデル比較記録

## 比較条件

- 実施日: 2026-07-26
- Henji: `/Users/masat/bin/henji`、v2.1.7
- 実行形式: `-q -a API -m MODEL --no-cache --max-tokens 1024 --json-schema FILE --json-schema-retries 0 PROMPT`、本文はstdin
- 固定prompt: 未信頼のWeb本文中の指示に従わず、主題と重要点を日本語1〜5行・400文字以内で要約するよう求める。
- 本文: 同日に抽出したFil-C、Senpai、YAMA HACK本文と、命令混入を含む合成本文。
- 代表ページの入力量: Fil-C 2,148文字・24ブロック、Senpai 2,259文字・56ブロック、YAMA HACK 1,750文字・37ブロック。
- 出力制約: JSON objectの`summary`のみ。空文字、6行以上、400 Unicode文字超過、未知fieldをShirushi側で拒否する。
